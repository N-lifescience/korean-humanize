# 간결한 문장 검토

습관적인 표현이나 같은 뜻의 반복 때문에 읽기가 늦어지는 문장에 적용한다. 글자 수를 줄이는 목표보다 의미와 말투의 보존을 우선한다. 아래 표현의 출현만으로 오류나 AI 문체라고 판단하지 않는다.

김정선의 『내 문장이 그렇게 이상한가요?』에서 소개하는 ‘적의를 보이는 것들’의 관점과 사용자가 제공한 글쓰기 요령 이미지 4장을 참고해 판단 기준을 구성했다. 적용 조건, 보존 기준과 아래 예문은 이 스킬에 맞게 작성했다.

## ‘적의를 보이는 것들’의 검토 대상

| ID | 살필 표현 | 덜어낼 수 있는 경우 | 보존할 역할과 예외 |
| --- | --- | --- | --- |
| K-1 | `-적`, `-적인`, `-적으로` | 익숙한 명사구나 직접적인 서술로 뜻이 그대로 전달되는 경우. `정기적인 점검` → `정기 점검` | 성질, 관점이나 범주를 구별하는 말과 정착한 전문용어. `통계적 유의성`, `법적 책임` 등을 글자 수 때문에 바꾸지 않는다. `목적`, `표적`처럼 낱말의 일부인 글자도 대상이 아니다. |
| K-2 | 조사 `의`와 그 연쇄 | 소유나 수식 관계가 이미 분명하고 합쳐 써도 관계가 같은 경우. `팀의 회의 일정` → `팀 회의 일정` | 소유자, 행위 주체, 대상이나 수식 범위를 구별하는 조사. 생략해 여러 해석이 생기면 유지하거나 문장을 풀어 쓴다. |
| K-3 | 형식적인 `것`, `것이다` | 앞말을 불필요하게 명사화하거나 같은 설명을 반복하는 종결. 단순 사실 전달에서 `설정을 바꾼 것입니다` → `설정을 바꿨습니다` | 실제 대상, 선택 범위, 대조, 강조, 설명의 초점이나 가능성 표현의 일부. `선택한 것만 삭제합니다`의 범위와 `문제가 생길 것 같습니다`의 유보를 보존한다. |
| K-4 | 복수 접미사 `들` | 수량이나 앞뒤 문맥으로 복수가 이미 분명한 경우. `선택한 두 개의 파일들` → `선택한 두 개의 파일` | 복수 자체가 새로운 정보이거나 집단, 분배, 개별 대상을 구별하는 경우. `저마다 다른 선택들`처럼 개별성을 드러내는 표현도 문맥을 보고 판단한다. |

## 첨부 글쓰기 요령의 문맥별 적용

이미지의 ‘있다’, ‘것’, ‘수’를 줄이자는 요령 중 `것`은 K-3에서 함께 다룬다. 나머지는 다음 기준으로 검토한다.

| ID | 살필 표현이나 구조 | 적용 기준 |
| --- | --- | --- |
| K-5 | `있다`, `-고 있다`, `-어 있다` | 기능 설명에서 `이 기능은 자동 저장을 지원하고 있습니다` → `이 기능은 자동 저장을 지원합니다`처럼 진행상이 별도 정보를 주지 않을 때만 간결하게 쓴다. 존재, 소유, 현재 진행, 지속과 결과 상태는 보존한다. `파일을 업로드하고 있습니다`, `연결이 끊겨 있습니다`를 완료나 단순 사실로 바꾸지 않는다. |
| K-6 | `수`, `-수 있다`, `-수도 있다` | 가능성, 능력, 허용과 불확실성을 먼저 구별한다. 같은 유보를 겹쳐 쓴 경우에만 동등한 강도로 정리한다. `연결이 끊길 수도 있습니다`를 `연결이 끊기기도 합니다`로 바꾸면 가능성이 실제 발생이나 빈도처럼 읽히므로 채택하지 않는다. 원문이 단순 가능성인지 경험적 사실인지 불분명하면 보존한다. |
| K-7 | 정보가 없는 문장과 추상적인 군말 | 앞 문장과 같은 말만 반복하고 정보, 논증, 장면, 관계나 안내 기능을 더하지 않는 구간을 덜어낸다. 인사, 위로, 예의, 독자의 안심도 문장의 기능이다. 조건, 예외, 주의사항, 행동 결과와 오류 복구 방법은 정보가 있으므로 짧게 만들려고 지우지 않는다. |
| K-8 | 할 말을 마친 뒤의 맺음말 | 내용이 끝난 뒤 같은 결론을 다시 선언하는 문장만 덜어낸다. 요청한 요약, 다음 행동, 근거의 한계와 주의사항은 유지한다. 소설과 에세이의 의도적인 여운이나 말투도 존중한다. |
| K-9 | `그리고`, `그래서`, `하지만`, `그러므로` 등 연결 표현 | 문장 순서나 내용만으로 관계가 분명하고 같은 연결어가 습관적으로 반복될 때 생략하거나 배치를 조정한다. 원인, 결과, 대조, 양보, 조건과 추론의 방향이 달라지거나 흐려지면 유지한다. 접속사를 줄인 자리에 원문에 없던 행동, 감정, 동기나 강조를 보태지 않는다. |

`-적`, `의`, `것`, `들`, `있다`, `수`, 접속사를 일괄 삭제하는 치환 규칙은 만들지 않는다. 형태나 빈도는 검토 후보를 찾는 단서로만 쓴다.

## 적용과 의미 확인

1. 문장 안에서 실제로 불필요한 구간과 그 이유를 찾는다. 필요한 표현이면 그대로 둔다. 진단을 기록할 때는 해당 K-ID, 원문 구간, 맥락과 보존할 의미를 적는다. 자동 집계되지 않는 K-ID를 정량 탐지 결과로 표현하지 않는다.
2. 앞뒤 문장을 함께 보며 해당 구간만 고친다. 추상적인 말 대신 쓸 주체, 행위나 수치가 원문에 없으면 만들어 넣지 않는다. 필요하면 불명확한 부분을 알려준다.
3. 원문과 결과의 주체, 행위, 대상, 수량, 시점, 진행과 완료, 조건, 부정, 가능성과 의무, 인과와 대조를 대조한다. 단어를 덜어내면서 소유 관계나 복수의 범위를 바꾸지 않았는지도 확인한다.
4. [내장 윤문 실행 절차](humanize-workflow.md)의 게이트와 함께 의미를 직접 확인한다. 수치 게이트의 통과만으로 진행상, 범위나 논리까지 보존됐다고 판단하지 않는다. 뜻이 달라진 수정은 되돌리고, 국소 수정으로 확실히 복구할 수 없으면 보존하거나 검토가 필요하다고 알린다.
