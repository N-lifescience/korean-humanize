# korean-humanize

한국어 윤문과 웹앱 화면 가독성을 함께 다루는 올인원 Codex 스킬입니다.

AI 문체와 번역투를 다듬는 지침, 의미 보존 검증 도구, 띄어쓰기와 줄바꿈 기준을 모두 포함합니다. 별도의 윤문 스킬을 설치하지 않아도 사용할 수 있습니다.

## 주요 기능

- 한국어 AI 문체 진단과 자연스러운 윤문
- 습관적인 `-적`, `-의`, `것`, `들`과 군더더기의 문맥별 검토
- 사실, 수치, 인용, 말투와 가능성 표현의 보존 검증
- 올바른 띄어쓰기와 어절 경계에서의 줄바꿈
- 문장과 의미 단위의 안내 문구 구성
- 가운데점 최소화와 버튼 이름의 일관성
- 한국어 웹앱의 반응형 배치, 긴 버튼과 오류 안내 확인
- 모바일, 태블릿, PC와 필요한 문자 확대 상태의 화면 검증

글만 요청하면 윤문을 수행합니다. 실제 웹앱을 수정하는 요청에는 문구와 CSS를 함께 다듬고 대표 화면을 확인합니다. 화면 배치만 바꾸는 경우에는 문구를 불필요하게 재작성하지 않습니다.

## 간결한 문장 검토

김정선의 『내 문장이 그렇게 이상한가요?』에서 소개하는 ‘적의를 보이는 것들’의 관점을 반영했습니다. `-적`, `-의`, `것`, `들`이 문장에서 어떤 역할을 하는지 살피고 불필요한 표현을 덜어냅니다. 사용자가 제공한 글쓰기 요령을 바탕으로 `있다`, `수`, 반복하는 맺음말과 접속사도 문맥에 따라 검토합니다.

진행 상태, 가능성, 복수의 범위와 인과관계를 보존하며 간결하게 다듬습니다. 적용 조건, 보존 기준과 예문은 [간결한 문장 검토](references/concise-korean.md)에서 확인하세요.

## 설치

Git과 Python 3가 필요합니다. 셸에서 다음을 실행하세요.

```bash
mkdir -p ~/.codex/skills
git clone https://github.com/N-lifescience/korean-humanize.git ~/.codex/skills/korean-humanize
```

이미 같은 폴더가 있다면 기존 설치와 비교한 뒤 업데이트하세요. 화면 검증에는 작업 환경에서 사용할 수 있는 브라우저나 렌더링 도구가 필요합니다.

## 사용

Codex에서 다음처럼 요청하세요.

```text
$korean-humanize 이 글의 번역투를 다듬되 수치와 말투는 유지해줘.
```

```text
$korean-humanize 이 웹앱의 한국어 문구와 줄바꿈을 다듬어줘.
가운데점을 줄이고 모바일부터 PC까지 읽기 쉽게 확인해줘.
```

```text
$korean-humanize 문구는 유지하고 이 화면의 단어 끊김과 버튼 넘침만 고쳐줘.
```

## 구성

```text
SKILL.md                       실행 범위와 통합 규칙
agents/openai.yaml             스킬 표시와 호출 정보
references/humanize-workflow.md 내장 윤문 실행 절차
references/concise-korean.md    군더더기 검토와 의미 보존 기준
references/web-layout.md       한국어 웹 레이아웃 기준
references/                    진단 규칙과 역할별 지침
scripts/                       윤문 준비와 검증 도구
```

이 스킬을 설치해도 다른 프로젝트의 전역 규칙 파일을 자동으로 수정하지 않습니다. 구체적인 처리 범위는 사용자의 요청을 따릅니다.
